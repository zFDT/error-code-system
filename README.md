# 设备错误码查询系统

面向设备（3D 打印机 / IoT 设备）的错误码管理与查询系统，让散落各处的设备错误码实现统一管理、快速查询与复现。

## 项目简介

设备在运行过程中会产生大量错误码，但这些错误码往往散落在文档、固件、日志与不同项目里，难以统一查询和复现。本系统面向 3D 打印机与 IoT 设备场景，提供一套集中的错误码管理后台：

- 将错误码集中录入、统一维护，解决「错误码散落各处、难以统一查询复现」的痛点
- 通过模块归类与项目维度管理，让错误码按业务边界有序组织
- 提供搜索与筛选，帮助开发者快速定位错误码并回溯设备问题

## 核心功能 / 技术特性

**核心功能**

- **错误码 CRUD**：对设备错误码进行新增、查看、编辑与删除，维护错误码的编号、描述与含义
- **模块归类**：将错误码归属到具体模块（modules），按业务模块维度组织错误码
- **项目维度管理**：通过项目（projects）维度隔离与管理不同设备 / 产品线的错误码
- **错误分类**：错误码按 errors 页面进行分类展示，便于按类别浏览
- **搜索与筛选**：支持按关键字搜索与条件筛选，快速定位目标错误码

**技术特性**

- **现代全栈独立搭建**：Nuxt 3 + Vue 3 作为前端框架，Prisma ORM 作为数据层，全栈一体独立完成
- **页面化组织**：error-code / errors / index / modules / projects 多页面覆盖错误码、模块与项目的完整管理链路
- **Server API + 数据模型分离**：Nuxt Server API 承载接口，Prisma schema 定义数据模型，职责清晰
